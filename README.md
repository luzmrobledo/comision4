# La Comisión 4 es la mejor 🏆

Una página web interactiva y divertida para la Comisión 4.

## 🚀 Características
- **Cartel principal:** "¿La comisión 4 es la mejor?"
- **Botón escurridizo:** El botón "No" se escapa cada vez que intentas hacerle clic o tocarlo en el móvil.
- **Celebración:** Al presionar "¡Sí!", se desata confeti y emojis gigantes festejando.
- **Efectos de sonido:** Sonidos sintetizados usando la Web Audio API (sin dependencias externas).

## 💻 Tecnologías
- HTML5
- CSS3 (Animaciones, Glassmorphism)
- JavaScript Vanilla & Canvas API
